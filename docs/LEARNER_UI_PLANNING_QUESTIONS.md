## 0. 이미 확정되어 다시 묻지 않는 내용

1. 교수자 로그인 후 연결 아동을 선택하는 2단계 학습 앱 로그인
2. 아동은 AI가 배정한 일일 커리큘럼을 순서대로만 수행
3. 잠긴 훈련 선택 시 이동하지 않고 `앞의 훈련부터 해보자!` 안내
4. 개별 훈련 완료 후 `다음 훈련 시작`, 마지막에는 `오늘 학습 완료`
5. 훈련 중 이탈 시 `계속 학습하기` / `그만하고 나가기` 확인
6. 안내·학습 모션은 모두 기리 토끼로 통일
7. 시선·마이크 헤더 아이콘은 조작 버튼이 아니라 연결 상태 표시 전용
8. 필수 장치가 없으면 해당 훈련 시작 차단, 선택 장치는 끊겨도 학습 지속
9. 성장 화단은 `파닉스`, `읽기`, `유창성` 3개
10. 성장 단계는 성취율 기준 5단계이며 단계 상승 시 애니메이션 표시
11. 이야기 목록은 읽던 책, 다른 책, 새로운 책을 구분
12. 같은 템플릿에서 생성한 이야기는 세션 ID 순서로 번호 부여
13. 완독한 책을 다시 읽으면 `last_read_at` 갱신
14. 이야기 질문은 선택지 없이 STT 답변으로 분기 생성
15. 질문 화면 진입 시 마이크 자동 시작
16. 생성 중 숫자 진행률 없이 기리 토끼와 반복 모션 표시
17. 다음 이야기의 글과 배경 이미지가 모두 준비된 뒤에만 다음 장 공개
18. 이야기 친구는 실제 생성·획득된 친구만 표시하고 0명이면 빈 상태 표시
19. 포인트·재화 시스템은 사용하지 않음
20. 성장 화면에서만 `이야기 친구들` 버튼 표시
21. 이야기 생성 실패 시 같은 요청을 다시 시도하며 상세 실패 UX는 이번 범위에서 보류
22. 이야기 본문과 배경 이미지 중 하나라도 준비되지 않으면 다음 장을 열지 않음
