## 서비스 요약

iRead는 난독증 아동의 읽기 학습을 보조하는 서비스입니다. 의료 진단이나 치료 도구가 아닙니다.

- 학습 앱: 아동이 테스트, 훈련, 이야기 읽기, 성장 기록을 수행합니다.
- 관리자 앱: 교수자·상담사가 아동, 커리큘럼, 훈련 이력, 테스트 이력, 보고서를 관리합니다.
- Spring Backend: 인증, 데이터 저장, 권한 검증, 통계, 파일 메타데이터를 담당합니다.
- FastAPI/AI: 시선·음성 분석, 취약점 추론, 교안 및 이야기 분기 생성을 담당합니다.
- Electron App: Windows EXE로 학습 앱과 Eye Tracker 로컬 모듈을 실행합니다.

## Codex 시작 순서

1. `CODEX_RULES.md`를 읽습니다.
2. `FUNCTIONAL_SPEC.md`에서 구현할 도메인의 사용자 흐름과 완료 조건을 확인합니다.
3. `API_SPEC.md`에서 연결할 API의 계약과 현재 구현 여부를 확인합니다.
4. `검수 필요`, `보류`, `TBD` 항목은 임의 확정하지 말고 코드에 TODO를 남깁니다.
5. 실제 백엔드 코드와 명세가 다르면 코드 변경 전에 차이를 보고합니다.
