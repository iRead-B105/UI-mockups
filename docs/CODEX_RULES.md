# iRead Codex 구현 규칙

## 1. 기본 원칙

- 명세에 없는 기능을 임의 추가하지 않습니다.
- `검수 필요`, `보류`, `TBD`는 코드로 확정하지 않고 TODO와 이슈로 남깁니다.
- 기존 코드와 명세가 충돌하면 먼저 차이를 정리합니다.
- ERD 또는 API 계약을 변경하면 `ERD_API_CHANGELOG.md`에 변경 내용과 이유를 같은 작업에서 기록합니다.
- 사용자 화면의 문구와 개발 주석은 한국어를 사용합니다.
- DTO, 변수, API 경로, 파일명은 영어를 사용합니다.

## 2. 백엔드

- Controller는 입력 변환과 응답만 담당합니다.
- Service에 비즈니스 로직을 둡니다.
- Repository/Mapper에 저장소 접근을 둡니다.
- 엔티티를 API 응답으로 직접 반환하지 않습니다.
- 모든 ID는 외부 JSON에서 문자열 직렬화를 우선 검토합니다.
- `teacherId`를 소유권 검증용 클라이언트 입력으로 받지 않습니다.
- 수정 API는 전달된 필드만 변경합니다.
- 생성·완료 API는 중복 호출에 안전해야 합니다.
- 이야기 AI 분기 저장과 진행률 갱신은 단일 트랜잭션입니다.
- 파일의 서버 내부 경로는 응답에 노출하지 않습니다.

## 3. 인증

- 관리자 앱과 학습 앱의 토큰 audience를 분리합니다.
- access token은 짧게, refresh token은 서버 세션과 rotation을 사용합니다.
- refresh cookie는 HttpOnly, Secure, SameSite를 사용합니다.
- 로그아웃 시 refresh session과 cookie를 폐기합니다.
- 아동 범위 access token은 다른 아동 자원에 접근할 수 없습니다.

## 4. API 응답

권장 성공 응답:

```json
{
  "success": true,
  "data": {},
  "meta": {
    "timestamp": "2026-07-26T12:00:00+09:00"
  }
}
```

권장 오류 응답:

```json
{
  "success": false,
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "요청한 데이터를 찾을 수 없습니다.",
    "details": {}
  },
  "meta": {
    "timestamp": "2026-07-26T12:00:00+09:00"
  }
}
```

## 5. 파일 업로드

- 음성은 `multipart/form-data`를 사용합니다.
- 허용 형식과 크기를 서버에서 재검증합니다.
- 파일명은 UUID 기반으로 생성합니다.
- 사용자 입력 파일명을 경로에 직접 사용하지 않습니다.
- 내부 저장 경로를 API 응답에 반환하지 않습니다.
- DB에는 파일 식별자, 저장 키, MIME type, 크기, 길이, 생성 시각을 저장합니다.

## 6. 프론트엔드

- Vue 3 + TypeScript 기준입니다.
- API 호출, 상태, 화면 컴포넌트를 분리합니다.
- 로딩·빈 상태·오류·재시도 상태를 모두 구현합니다.
- 저장 중 버튼을 잠급니다.
- 같은 요청을 중복 전송하지 않습니다.
- 아동용 화면은 큰 글자·큰 버튼·낮은 정보 밀도를 유지합니다.
- 이미지가 없으면 임의 생성하지 않고 `리소스 추가 필요` placeholder를 사용합니다.
- 시선·음성 권한 오류는 아동이 이해할 수 있는 문구와 교수자용 상세 원인을 분리합니다.
- 모든 안내·학습·반응 모션은 기리 토끼를 사용합니다. 획득 캐릭터로 모션 캐릭터를 교체하는 기능을 추가하지 않습니다.

## 7. 데이터 수집

- 음성, 시선, 선택 응답의 세션 ID를 분리합니다.
- 각 데이터는 문항 번호와 콘텐츠 식별자에 연결합니다.
- 클라이언트 시각만 신뢰하지 않고 서버 수신 시각을 저장합니다.
- 시선 수집 실패가 선택·음성 응답 저장을 무조건 롤백시키지 않게 합니다.
- 원시 데이터와 집계 데이터의 보존 정책을 분리합니다.

## 8. AI

- 생성 입력과 결과에 schema validation을 적용합니다.
- 프롬프트 버전, 모델 버전, 생성 시각을 기록합니다.
- 생성 결과를 저장하기 전에 금칙어, 길이, 목표 음운, 진행률을 검증합니다.
- 실패 시 기존 커리큘럼·이야기 진행 상태를 변경하지 않습니다.
- 의료 진단처럼 표현하지 않습니다.

## 9. 테스트

최소 테스트 범위:

- 인증 성공·실패·만료·갱신
- 다른 교수자의 아동 접근 차단
- 다른 아동 범위 토큰 접근 차단
- 중복 제출
- 파일 형식·크기 오류
- 녹음 미감지
- 시선 장치 연결 끊김
- 커리큘럼 저장 충돌
- AI 응답 schema 오류
- 이야기 분기 트랜잭션 롤백
