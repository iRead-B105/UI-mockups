# iRead 아동용 UI 기획 답변지

## 1. 오늘 커리큘럼·훈련 복구

- Q01 오늘 커리큘럼 생성 중: `오늘 학습을 준비하고 있어!` 대기 화면 + 자동 재조회
- Q02 훈련 0개인 날: 휴식일 허용, `오늘은 쉬는 날이야!`
- Q03 완료 후 재진입: `오늘 학습 완료` 화면 재표시
- Q04 진행 중 훈련 재접속: 커리큘럼 지도에서 현재 발판을 먼저 보여주고 선택 시 복귀
- Q05 비정상 종료 복원 단위: 완료 문항까지만 저장, 수행 중 문항은 처음부터 재시작
- Q06 자발적 중단 후 재시작: 해당 훈련 처음부터 재시작
- Q07 커리큘럼 수정 반영 시점: 시작한 회차는 고정, 다음 회차부터 변경 반영
- Q08 커리큘럼 학습일 필드: 날짜별 사전 일정이 아닌 다음 회차 구조. 실제 완료 날짜를 학습일로 처리

## 2. 훈련 결과·피드백

- Q09 오답 재시도: 최대 3회 직접 시도 후 자동 힌트, 힌트 사용은 내부 데이터에만 기록
- Q10 자동 힌트: 수동 버튼 제거, 자동 시각 힌트 유지
- Q11 저장할 시도 이력: 최초 오답·재시도 횟수·힌트 사용·최종 성공 모두 저장
- Q12 STT 실패와 발음 오답: 미감지·STT 오류는 재시도 안내, 목표 발음 불일치는 오답 및 시도 증가
- Q13 음성 훈련 성공 기준: 서버·템플릿이 임계값 관리, UI는 `success`만 사용
- Q14 유창성 제한 시간 종료: 화면에는 시간 제한 미표시, 서버는 측정 시간 기록
- Q15 TTS 재생 횟수: 제한 없음, 재생 횟수만 저장
- Q16 훈련 저장 실패: 로딩 중 자동 재시도, 2회 실패 뒤 일반 오류 안내
