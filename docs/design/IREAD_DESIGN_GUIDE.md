# 아이리드 디자인 가이드

## 학습 화면의 정보 최소화

아이리드의 학습 화면은 난독 아동이 핵심 과제에 집중할 수 있도록 필요한 정보만 표시한다.

### 필수 원칙

- 문제 해결에 직접 필요하지 않은 분류명, 단계명, 작은 라벨은 표시하지 않는다.
- `음운 인식`, `오늘의 낱말`, `학습 유형`처럼 보호자나 교사를 위한 메타 정보는 아동의 문제 화면에서 제거한다.
- 같은 의미의 안내 문장을 두 번 이상 반복하지 않는다.
- 화면에는 문제 지시문, 학습 대상, 선택지, 필수 행동 버튼과 즉각적인 결과만 남긴다.
- 보조 설명이 필요하면 긴 문장보다 음성 안내를 우선한다.
- 한 화면에서 아동이 읽어야 하는 문장 수와 시각적 강조 지점을 최소화한다.
- 작은 배지와 장식 텍스트를 정보 계층을 만드는 용도로 사용하지 않는다.
- 새로운 요소를 추가할 때는 `이 정보가 정답을 선택하거나 다음 행동을 이해하는 데 필요한가?`를 확인하고, 아니라면 추가하지 않는다.

### 시선·음성 상호작용 공통 원칙

- 시선 위치는 중심이 투명한 원과 반투명 외곽선으로 표시한다. 글자나 그림을 가리지 않도록 불투명한 점이나 큰 포인터를 사용하지 않는다.
- 시선으로 진행한 결과는 이탈해도 초기화하지 않는다. 아동이 이미 수행한 구간은 화면에 그대로 남긴다.
- 3초 이상 시선 진행이 멈추면 마지막 진행 지점의 다음 목표만 부드럽게 반짝여 다시 시작할 위치를 알려준다.
- 시선 선택에는 원형 진행 표시를 사용해 선택이 확정되기 전 남은 시간을 직관적으로 보여준다.
- TTS 안내는 화면에 적힌 짧은 지시를 대신하거나 보완한다. 화면 문구와 같은 내용을 긴 음성으로 반복하지 않는다.
- STT를 사용하는 활동은 기술 용어와 인식 점수를 숨기고 `말하기`, `한 번 더 말해봐요`, `잘했어요`처럼 행동과 결과만 전달한다.
- 시선 추적기나 마이크가 없는 개발 환경에서도 마우스·터치와 대체 동작으로 전체 학습 흐름을 검증할 수 있어야 한다.

### 첫소리 찾기 화면 적용

- 유지: 문제 지시문, 대상 낱말과 그림, 소리 듣기, 자음 선택지, 선택 및 다음 버튼
- 제거: 학습 대분류, 활동 유형, `오늘의 낱말` 라벨, 반복 안내 문구, 힌트 버튼

### 같은 소리·끝소리 찾기 화면 적용

- 같은 소리 찾기는 대상 낱말의 소리와 큰 낱말 선택 카드 3개만 제시한다. 각 선택지는 글을 읽지 않아도 비교할 수 있도록 바로 들을 수 있어야 한다.
- 끝소리 찾기는 대상 낱말과 소리 듣기, 큰 자음 선택 카드 3개만 제시한다.
- 두 화면 모두 분류명, 활동 유형, 작은 설명 라벨, 힌트 버튼과 중복 안내 문구를 표시하지 않는다.
- 실제 낱말 그림 리소스가 없으면 관련 없는 그림이나 임시 이미지를 사용하지 않고, 낱말과 음성 중심의 카드로 구현한다.

### 소리 나누기·합치기 화면 적용

- 서비스의 `글자 자르기`는 글자 모양을 물리적으로 자르는 활동이 아니라, 글자·낱말의 소리 단위를 탈락하거나 대치해 새로운 결과를 만드는 음운 조작 활동이다.
- 글자 자르기는 `받침 빼기`, `음절 빼기`, `음절 바꾸기`의 세 소분류로 제공한다. 예: `닭 → 다`, `바나나 → 바나`, `사과 → 사장`.
- 탈락 활동은 소리 조각을 클릭하면 해당 조각이 회색·반투명으로 바뀌고 취소선을 표시한다. 같은 소리가 반복되어 어느 조각을 빼도 결과가 같다면 모든 가능한 위치를 정답으로 인정한다.
- 대치 활동은 바꿀 소리 조각을 클릭해 흐리게 만든 뒤, 새 소리 카드 3개 중 하나를 선택한다.
- 2회 실패하면 조작해야 할 원래 소리가 반짝이고, 3회 실패하면 가위 표시와 점선으로 탈락 위치를 직접 알려준다. 대치 문제에서는 정답 대치 카드도 함께 강조한다.
- 완료 시 결과 글자나 낱말만 TTS로 한 번 읽는다. 조작한 소리 전체를 다시 나열하거나 따라 말하기를 요구하지 않는다.
- 서비스의 `소리 나누기`는 음절 생략 과제로 운영한다. 원래 낱말을 음절 조각으로 제시하고, 목표 소리를 들은 뒤 불필요한 조각 하나를 탈락시켜 결과 낱말을 만든다. 예: `바나나`에서 `바나`를 들으면 `나` 하나를 뺀다.
- 학술 용어의 `분절(segmentation)`은 `코끼리 → 코/끼/리`, `불 → ㅂ/ㅜ/ㄹ`처럼 한 낱말을 구성 소리로 나누는 별도 과제다. 음절 생략 UI와 카드 재배열 UI를 혼용하지 않는다.
- 소리 합치기는 나뉜 소리 듣기, 음절 빈칸, 큰 음절 카드, 완성 낱말과 확인 버튼만 표시한다.
- 소리 나누기는 뺄 음절을 직접 누르고, 소리 합치기는 카드를 드래그 앤 드롭하거나 눌러 배치한다.
- 조작 방법을 긴 문장으로 반복 설명하지 않고, 빈칸과 카드의 위치·크기만으로 행동을 이해할 수 있게 한다.
- 힌트 버튼, 활동 유형, 단계 설명과 교사용 메타 정보는 표시하지 않는다.

### 파닉스 화면 적용

- 글자 따라 보기는 `자음 하나`, `모음 하나`, `완성 글자 하나`를 각각 독립된 소분류로 제공한다.
- 글자 따라 보기 화면에는 현재 글자, 흰색 획 테두리, 획순 점선, 시선 위치만 표시한다. `오늘의 낱말`, 훈련 유형, 단계 설명처럼 수행에 필요하지 않은 정보는 넣지 않는다.
- 시선이 획순을 따라가면 지나간 구간을 한 가지 강조색으로 채운다. 획순을 건너뛰거나 다음 목표에서 먼 위치를 바라보는 동작은 진행으로 처리하지 않는다.
- 따라 보기가 끝나면 캐릭터가 TTS로 `따라 해봐, ㄱ`처럼 말하고, 아동이 같은 소리를 말해 STT 확인을 받아야 해당 문항을 완료한다.
- 자음 이름과 실제 발음처럼 STT 결과가 달라질 수 있는 항목은 허용 발음 목록을 문항 데이터에 둔다. 예: `ㄱ`, `기역`, `그`.
- 소리 듣고 고르기는 `글자 소리 → 같은 글자 고르기`와 `낱말 소리 → 첫소리 글자 고르기`를 서로 다른 소분류로 제공한다.
- 소리 듣고 고르기의 선택지는 큰 글자 카드 3개로 고정하고, 현재 단계에서는 시선 체류가 아닌 마우스·터치 클릭으로 선택한다.
- 선택 카드를 누르면 별도의 `확인` 버튼 없이 즉시 정답을 판정한다. 정답이면 캐릭터가 `맞았어!`라고 말하고 문항을 완료하며, 따라 말하기 단계는 넣지 않는다.
- 낱말 첫소리 문제는 정답을 유추할 수 있는 낱말 텍스트를 화면에 미리 표시하지 않고 음성으로만 제시한다.
- 글자 만들기는 `초성+중성`, `초성+중성+받침`, `초성+중성+겹받침`의 세 소분류로 점진적으로 확장한다. 겹받침은 `ㄺ`, `ㄻ`, `ㅄ`처럼 한 장의 받침 카드로 다룬다.
- 만들 글자는 화면에 미리 노출하지 않고 소리로만 들려준다. 아동은 글자 카드 4장 중 필요한 카드를 골라 순서가 있는 빈칸에 드래그한다.
- 기본 글자는 정답 카드 2장과 방해 카드 2장, 받침·겹받침 글자는 정답 카드 3장과 방해 카드 1장을 제공한다.
- 2회 실패하면 필요한 카드만 부드럽게 반짝이고, 3회 실패하면 기존 배치를 비운 뒤 각 빈칸에 들어갈 글자를 옅게 표시한다. 별도의 힌트 버튼은 두지 않는다.
- 글자가 완성되면 완성 글자를 화면에 보여주고 TTS가 해당 글자만 한 번 읽는다. 따라 말하기 단계는 넣지 않는다.
- 한글 만들기 게임은 토끼·거북이·개미 캐릭터와 사용자가 자음·모음 타일로 제시된 낱말을 먼저 완성하는 3판 대결로 운영한다.
- 상대 난이도는 `토끼 → 거북이 → 개미` 순으로 높아진다. 토끼는 기본 자모 낱말, 거북이는 받침 낱말, 개미는 겹받침 낱말을 사용하며 상대의 조합 속도도 단계별로 빨라진다.
- 아동은 마우스나 터치 포인터로 한글 타일을 순서가 있는 빈칸에 드래그한다. 마지막 타일이 올바르게 놓이는 즉시 해당 판의 승자를 결정한다.
- 숫자 초시계, 제한 시간 문구와 목숨은 표시하지 않는다. 대신 상대의 뒤집힌 타일이 하나씩 채워지는 모습으로 진행만 보여준다.
- 매 판 승패와 별 반응을 크게 표시하고, 3판이 끝나면 `2:1`처럼 최종 점수와 최종 승자를 별도 화면에서 분명히 보여준다.
- 각 판이 끝나면 완성한 낱말만 TTS로 읽고, 따라 말하기 단계 없이 다음 판으로 진행한다.
- 자음·모음 소리 익히기와 비슷한 소리 구별하기는 큰 소리 듣기 버튼 하나와 글자 카드 3개만 제시한다. 정답 글자는 듣기 전에 화면에 따로 노출하지 않는다.
- 비슷한 소리는 한 문제에서 비교할 소리 수를 2~3개로 제한하고, 카드 크기·색·위치는 동일하게 유지해 글자 모양과 소리에만 집중하게 한다.
- 받침 소리는 대상 낱말과 소리 듣기, 받침 카드 3개, 확인 버튼만 표시한다.
- 자음과 모음 합치기는 빈칸, 이동할 카드, 완성 글자와 확인 버튼만 유지하며 힌트 버튼과 반복 조작 설명은 표시하지 않는다.

### 짧은 글 화면 적용

- 한 화면의 읽기 대상은 한 문장 또는 한 낱말로 제한하고, 어절·음절 묶음을 큰 고정 크기로 표시한다.
- 문장 쓰기·조립 훈련은 `문장 속 빈칸 하나 채우기`와 `빈 화면에서 문장 전체 조립하기`의 두 단계로 제공한다. 두 단계를 한 화면에서 섞지 않는다.
- 빈칸 문제는 한 문장, 빈칸 하나, 큰 낱말 선택지 3개만 제시한다. 아동은 낱말 카드를 빈칸으로 직접 드래그하며, 카드를 누르기만 했을 때는 TTS를 재생하거나 정답을 판정하지 않는다.
- 잘못된 낱말은 빈칸에 남지 않고 즉시 원래 위치로 돌아간다. 화면에는 `한 번 더 해봐요`만 표시하고 정답 설명, 점수와 실패 횟수는 보여주지 않는다.
- 빈칸 문제에서 2회 실패하면 정답 낱말 카드와 빈칸 테두리만 부드럽게 반짝인다. 별도의 힌트 버튼과 긴 힌트 문장은 사용하지 않는다.
- 정답 낱말을 넣으면 완성된 문장을 그대로 유지하고, 아동이 문장 전체를 STT로 한 번 읽어야 문항을 완료한다. 낱말 선택 과정과 완성 직후에는 모범 TTS를 자동 재생하지 않는다.
- 문장 전체 조립 문제는 정답 문장을 미리 표시하지 않고, 학습 데이터에 따라 3~5개의 빈칸과 같은 수의 섞인 어절 카드만 제시한다.
- 어절 카드는 클릭으로 배치하거나 TTS를 재생하지 않는다. 아동이 카드를 원하는 빈칸으로 직접 드래그하며, 이미 놓인 카드 위로 다른 카드를 드래그하면 두 카드의 위치를 교환할 수 있다.
- 모든 빈칸이 채워지면 확인 버튼 없이 즉시 문장 전체 순서를 판정한다. 틀린 위치의 카드만 붉게 흔든 뒤 카드 영역으로 돌려보내고, 올바른 위치의 카드는 빈칸에 그대로 유지한다.
- 문장 전체 조립에서 2회 실패하면 다음 빈칸에 들어갈 정답 카드와 해당 빈칸의 테두리만 반짝인다. 정답 문장, 낱말 번호, 긴 힌트 문장과 힌트 버튼은 표시하지 않는다.
- 문장을 올바르게 조립한 뒤에는 완성된 배치를 그대로 유지하고, 아동이 문장 전체를 STT로 읽어야 문항을 완료한다. 자동 TTS, 그림, 점수와 확인 버튼은 사용하지 않는다.
- 그림과 문장 연결하기는 한 화면에 의미가 분명한 큰 그림 하나, 그림 아래의 문장 빈칸 하나, 문장 카드 3개만 제시한다.
- 문장 카드는 개별 소리 버튼이나 클릭 TTS를 제공하지 않는다. 아동이 문장 카드를 그림 아래 빈칸으로 직접 드래그했을 때만 정답을 판정한다.
- 오답 문장은 빈칸에 남지 않고 카드 영역으로 돌아가며 `한 번 더 해봐요`만 표시한다. 2회 실패하면 정답 문장 카드와 문장 빈칸의 테두리만 반짝인다.
- 정답 문장이 연결되면 해당 문장을 TTS로 한 번 읽고 문항을 완료한다. 이 활동에서는 별도의 따라 읽기 STT 단계를 두지 않는다.
- 문제 그림은 문장 의미와 정확히 일치하는 아동용 일러스트 에셋을 사용한다. 의미를 추측하기 어려운 기호, 이모지와 관련 없는 임시 이미지는 사용하지 않는다.
- 그림과 문장 연결 화면에는 점수, 확인 버튼, 힌트 버튼과 정답 설명을 표시하지 않는다.
- 어려운 낱말은 음절을 시각적으로 분리하되 원래 낱말을 동시에 반복 표기하지 않는다.

### 유창성 화면 적용

- 낱말 읽기는 `실제 낱말 읽기`와 `비단어 읽기`를 서로 다른 소분류로 제공한다. 아동 화면에는 실제 낱말·비단어 같은 분류 설명을 반복 표시하지 않는다.
- 한 화면에는 낱말 4개만 2×2로 배치하고, 읽기 순서는 왼쪽 위에서 오른쪽 아래로 고정한다. 현재 읽을 낱말은 큰 테두리로 강조하고, STT가 올바른 발음을 확인하면 다음 낱말로 강조를 옮긴다.
- 시선 위치는 글자를 가리지 않는 투명 중심·반투명 테두리의 원으로 표시한다. 점수, 정확도, 발음 분석값은 표시하지 않는다.
- 최초 화면에서는 낱말 TTS를 재생하지 않는다. 같은 낱말의 발음 실패가 2회 누적되거나 8초 동안 어느 낱말도 완료하지 못한 경우에만 현재 미완료 낱말을 왼쪽부터 밝게 빛낸다.
- 빛나는 낱말을 1초 이상 계속 응시하면 TTS가 그 낱말만 한 번 읽는다. TTS가 끝난 뒤 같은 낱말을 다시 발음하도록 STT를 자동으로 이어간다.
- 오답 때는 `한 번 더 읽어봐요`만 보여주며 실패 횟수와 평가 점수를 숨긴다. 네 낱말을 모두 읽으면 완료 상태와 다음 버튼만 표시한다.
- 문장 읽기는 한 화면에 한 문장만 표시하고 그림, 모범 음성 버튼, 문장 분류와 부가 설명을 함께 노출하지 않는다.
- 문장은 어절 단위로 나누되 하나의 자연스러운 문장처럼 이어서 배치한다. 현재 읽을 어절에만 큰 테두리를 표시하고, STT가 확인한 어절은 완료 표시를 남긴 뒤 다음 어절로 강조를 옮긴다.
- 아동이 문장 전체를 자연스럽게 이어 읽으면 한 번의 STT 결과에서 순서대로 확인된 연속 어절만큼 진행할 수 있다. 앞 어절을 건너뛴 결과는 이후 어절의 완료로 처리하지 않는다.
- 현재 어절의 발음 실패가 2회 누적되거나 8초 동안 어느 어절도 완료하지 못하면 현재 어절만 왼쪽부터 밝게 빛낸다. 빛나는 어절을 1초 이상 응시하면 해당 어절만 TTS로 한 번 읽고 STT 읽기를 다시 이어간다.
- 문장 읽기에서도 점수, 정확도, 실패 횟수를 표시하지 않으며 오답 문구는 `한 번 더 읽어봐요`로 제한한다.
- 여러 문장 읽기는 `두 문장`, `세 문장`처럼 길이별 소분류를 만들지 않는다. 하나의 읽기 활동이 학습 데이터에 포함된 문장 배열의 길이를 받아 필요한 줄 수를 가변적으로 생성한다.
- 각 문장은 한 줄 단위로 배치하고 현재 문장의 현재 어절만 강조한다. 한 문장을 완료하면 크기를 바꾸거나 접지 않고 같은 위치에 연하게 유지한다.
- 한 문장을 완료한 뒤 1초 동안 강조를 비우고 다음 문장의 첫 어절로 자동 이동한다. 별도의 `다음 문장` 버튼은 표시하지 않는다.
- 여러 문장에서도 어절별 STT, 2회 발음 실패 또는 8초 정체, 1초 시선 응시 후 해당 어절 TTS 규칙을 동일하게 적용한다.
- 여러 문장 화면에도 그림과 최초 모범 TTS를 넣지 않으며 데이터로 주어진 모든 문장을 읽은 뒤에만 문항을 완료한다.
- 단어 이어 읽기, 끊어 읽기, 반복 읽기, 짧은 이야기 읽기는 모두 모범 음성 듣기와 큰 읽기 묶음, 녹음 버튼, 다음 버튼만 유지한다.
- 끊어 읽기에서는 의미가 이어지는 어절을 하나의 시각적 묶음으로 보여준다.
- 반복 읽기는 같은 문장을 여러 문제에서 다시 제시해 익숙함을 만들며 속도 점수나 경쟁 요소를 표시하지 않는다.
- 짧은 이야기는 한 화면에서 두 문장을 넘기지 않고 마침표 단위로 묶어 표시한다.
- 녹음 시간, 파형, 다시 녹음은 조작에 필요한 범위에서만 보여주고 기술 용어, 목업 여부, 발음 점수는 아동 화면에 표시하지 않는다.

### 이야기 나라 독서 화면 적용

- 기존 학습자 헤더를 그대로 유지해 로고나 홈 버튼으로 언제든 메인 화면에 돌아갈 수 있게 한다.
- 독서 화면은 연노란색의 큰 프레임 안에 이야기 배경 그림과 본문을 함께 배치한다.
- 한 페이지의 본문은 약 60글자, 두 줄을 기준으로 하며 작은 제목, 분류명과 부가 설명을 함께 표시하지 않는다.
- 실제 시선 추적 좌표와 개발 환경의 마우스 위치를 같은 방식으로 처리한다. 시선 위치는 글자를 가리지 않는 투명 중심·반투명 테두리의 원으로 표시한다.
- 시선이 지나간 어절까지 읽기 진행 표시를 연하게 남기며, 본문 밖으로 3초 이상 이탈하면 다음에 읽을 어절 하나만 부드럽게 반짝인다.
- 페이지 하단에는 현재 쪽을 나타내는 단순한 점 표시와 큰 `다음 페이지` 버튼만 둔다. 마지막 페이지에서는 같은 위치의 버튼을 `책 덮기`로 바꾼다.
- `이야기 이어 읽기`는 책별 마지막 페이지를 불러오고, `새로운 이야기`에서 선택한 책은 첫 페이지부터 시작한다.
